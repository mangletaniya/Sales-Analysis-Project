# Sales Analysis Dashboard

## 📊 Project Overview

This project focuses on analyzing sales data to identify important business insights and sales trends. The analysis was performed using Python in Google Colab, with data processing, analysis, and visualization to understand sales performance.

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## 🔍 Key Analysis

* Data cleaning and preprocessing
* Sales and revenue analysis
* Monthly sales analysis
* Regional performance analysis
* Product-wise sales analysis
* Units sold analysis
* Identification of top-performing products
* Data visualization and dashboard creation

## 📁 Project Files

* `3. Sample Sales Data.xlsx` – Dataset used for the analysis

## 🎯 Objective

The main objective of this project is to analyze sales data and convert raw data into meaningful business insights using Python and data visualization techniques.

* Exploratory Data Analysis
